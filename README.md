# لوحة تحكم معمل اللغات (Django + Veyon + WebRTC)

تعمل على جهاز المعلم، وتدير أجهزة الطلاب من 1 إلى 40:

- **لوحة المعمل** (`/`): الأخضر متصل، الرمادي الباهت غير متصل، المخطط "غائب"، والإطار الأحمر "محظور". تحديد أجهزة وحظرها وفتحها وتغييبها.
- **الصوت الحي** (أزرار الصوت في اللوحة): بث صوت المعلم لأجهزة محددة أو للكل، والاستماع لطالب، والحوار مع طالب.
- **صفحة الإعداد** (`/setup/`): تشرح كيف يتصل كل جهاز بجهاز المعلم، وتفحص الاتصال لكل جهاز، وتولّد الأوامر الجاهزة.
- **صفحة الطالب** (`/student/`): تفتحها أجهزة الطلاب فقط، ولا يصل الطلاب لأي صفحة غيرها.

## كيف تتصل الأجهزة بجهاز المعلم

لكل جهاز طالب قناتان، ولا يعمل النظام كاملًا إلا بالاثنتين:

| القناة | الوظيفة | المنفذ | تعمل عندما |
|---|---|---|---|
| ① Veyon | الحظر والفتح (المعلم يرسل أوامر للطالب) | 11100 على جهاز الطالب | خدمة Veyon تعمل على جهاز الطالب |
| ② صفحة الطالب | الصوت والتحدث (WebSocket للإشارات ثم WebRTC للصوت) | 8000 على جهاز المعلم | صفحة الطالب مفتوحة في المتصفح |

كل جهاز يُعرَّف بعنوان IP الخاص به، وكل رقم من 1 إلى 40 مرتبط بعنوان واحد. صفحة **الإعداد والاتصال** (رابطها أعلى اللوحة) تعرض لكل جهاز حالة القناتين وما المطلوب إن لم يتصل.

## التشغيل على جهاز المعلم

```bat
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py setup_lab --ip-prefix 192.168.1. --ip-start 101
set LAB_SIMULATE=0
python manage.py runserver 0.0.0.0:8000 --noreload
```

### التشغيل من VS Code

افتح **Run and Debug** واختر **Django: تشغيل محلي (محاكاة)** ثم اضغط F5. يستخدم الإعداد بيئة `.venv` الموجودة في المشروع، ويشغّل الخادم على المنفذ 8000 بعملية واحدة مع `LAB_SIMULATE=1`؛ لن يرسل أوامر فعلية إلى Veyon.

ثم افتح **http://localhost:8000** (وليس عنوان الشبكة، وإلا منع المتصفح الميكروفون). الخطوات بعدها كلها من صفحة الإعداد:

1. من قسم "أوامر جاهزة" انسخ أمر فتح المنفذ في جدار الحماية ونفّذه مرة واحدة على جهاز المعلم.
2. على كل جهاز طالب: ثبّت Veyon كما في الأسفل، وأنشئ اختصار صفحة الطالب بالأمر الجاهز.
3. فعّل **وضع الربط**، وافتح الاختصار على كل جهاز طالب واختر رقمه، فيُسجَّل عنوانه تلقائيًا (أو اكتب العناوين بنفسك من الجدول).
4. راقب الجدول حتى يصير كل صف "جاهز"، وأوقف وضع الربط.

## تجهيز Veyon (مرة واحدة)

1. ثبّت Veyon على جهاز المعلم (مكوّن Master) وعلى أجهزة الطلاب (مكوّن Service).
2. على جهاز المعلم: Veyon Configurator ← المصادقة ← أنشئ زوج مفاتيح وصدّر المفتاح العام، واستورده على كل جهاز طالب.
3. اجعل حسابات الطلاب في Windows غير إدارية حتى لا يوقفوا خدمة Veyon.
4. شغّل `veyon-cli feature list` على جهاز المعلم وتأكد من اسم ميزة قفل الشاشة. الافتراضي `ScreenLock`، ولتغييره اضبط `VEYON_LOCK_FEATURES`.

## استخدام الصوت

- **تشغيل الصوت**: يطلب إذن الميكروفون ويتصل بكل طالب فتح صفحة الطالب.
- **بث للمحدد / بث للكل**: يصل صوت المعلم لسماعات الطلاب.
- **استمع للمحدد**: يفتح ميكروفون طالب واحد، ويظهر له تنبيه "المعلم يستمع إليك الآن".
- **حوار مع المحدد**: بث واستماع مع طالب واحد.

## الأمان

- لوحة المعلم والإعدادات وصفحة الإدارة تفتح من جهاز المعلم فقط. أجهزة الطلاب تصل إلى `/student/` وقناة الصوت الخاصة بها فقط.
- وضع الربط يسمح لأي جهاز بتسجيل نفسه ما دام مفعّلًا، فأوقفه بعد الانتهاء.
- غيّر `DJANGO_SECRET_KEY` عند الاستخدام الفعلي.

## متغيرات البيئة

| المتغير | الافتراضي | المعنى |
|---|---|---|
| `LAB_SIMULATE` | `1` | `1` وضع تجريبي لفحص Veyon والحظر، `0` تشغيل فعلي |
| `VEYON_CLI` | `C:\Program Files\Veyon\veyon-cli.exe` | مسار veyon-cli |
| `VEYON_PORT` | `11100` | منفذ خدمة Veyon على الطلاب |
| `VEYON_LOCK_FEATURES` | `ScreenLock` | ميزات الحظر مفصولة بفواصل |
| `LAB_CHECK_TIMEOUT` | `0.8` | مهلة فحص الاتصال بالثواني |
| `DJANGO_SECRET_KEY` | قيمة تطويرية | غيّرها عند الاستخدام الفعلي |

## ملاحظات

- شغّل الخادم بعملية واحدة (`--noreload`)، فحالة الاتصال تُحفظ في الذاكرة.
- الحظر ينتهي عند إطفاء الجهاز، فتُصفَّر علامة "محظور" تلقائيًا عند انقطاع اتصاله.
- الصوت يحتاج Chrome أو Edge على أجهزة الطلاب، وخيارات الاختصار الجاهز ضرورية: تسمح بالميكروفون على عنوان `http` المحلي وتشغيل الصوت تلقائيًا.
- المرحلة التالية: المحادثة الثنائية بين طالبين وتسجيل نطق الطلاب.
